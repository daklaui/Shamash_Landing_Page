# UI/UX System

## Design Character

The Shamash IT website must feel:

- Bright
- Premium
- Enterprise-ready
- Clear
- Trustworthy
- Sophisticated
- Practical
- Business-oriented

It should communicate intelligence and technical strength without becoming dark, cold, or overly futuristic.

## Layout Principles

- Use white and light neutral surfaces as the default.
- Use generous spacing, but avoid empty marketing fluff.
- Keep sections full-width with constrained inner content.
- Use cards for repeated items, tools, product previews, and callouts.
- Avoid putting cards inside other cards.
- Let dashboards and workflow previews carry the technical story.
- Place services prominently, not as a small icon strip.
- Make audience routing easy to scan.

## Page Widths

Recommended layout values:

- Max content width: `1200px` to `1280px`
- Narrow text width: `680px` to `760px`
- Wide visual width: `1440px` max for immersive bands
- Section vertical padding desktop: `88px` to `128px`
- Section vertical padding mobile: `56px` to `80px`

## Typography

Recommended fonts:

- Inter
- Manrope
- Plus Jakarta Sans

Use one primary typeface across the website.

Suggested scale:

```txt
Hero title: 56px to 64px desktop, 36px to 42px mobile
Section title: 38px to 46px desktop, 28px to 34px mobile
Card title: 20px to 24px
Body large: 18px to 20px
Body: 16px
Small: 14px
Label: 12px to 13px, uppercase or semibold
```

Do not scale font size directly with viewport width. Use defined responsive classes.

## Color Usage

### Base

- Page background: white or `#F8FAFC`
- Main headings: `#242850` or `#111827`
- Body text: `#374151`
- Secondary text: `#6B7280`
- Borders: `#E5E7EB`

### Brand

- Primary action: `#35A8DE`
- Secondary action: `#505CA2`
- Premium accent: `#E9AE11`
- Footer and high-contrast panels: `#242850`

## Buttons

Primary button:

- Shamash Blue background
- White text
- Slight hover darkening
- Clear focus ring
- Used for main CTAs

Secondary button:

- White or transparent background
- Indigo or navy text
- Border using light neutral or indigo tint
- Used for secondary exploration

Gold accents:

- Use only for small premium badges, highlights, or metric details.

## Cards

Cards should have:

- White background
- 1px border using light neutral
- 8px to 12px radius
- Soft shadow only on hover or selected emphasis
- Clear title, description, tags, and CTA

Avoid oversized decorative cards that make the site feel like a template.

## Icons

Use a consistent icon library such as Lucide React.

Recommended icon areas:

- Header dropdowns
- Audience router cards
- Service pillars
- Feature lists
- Process timeline
- CTA buttons

Icons should be line-based, simple, and professional.

## Dashboard Mockups

Use realistic but brand-consistent software interface mockups.

Each mockup should:

- Show plausible product data
- Use the Shamash color palette
- Contain dashboards, charts, tables, statuses, workflows, document lists, or app screens
- Explain what the product does

Do not use decorative visuals that only look technical but say nothing.

## Motion

Use subtle motion:

- Hero slider transitions
- Hover states
- Small dashboard metric animations
- Gentle reveal on scroll if implemented

Avoid:

- Excessive parallax
- Fast auto-rotation
- Constant movement
- Distracting decorative animation

Respect `prefers-reduced-motion`.

## Services Presentation

Services must be prominent.

Use four large primary pillars:

- Enterprise Software Engineering
- AI Automation and Digital Transformation
- Cloud, Infrastructure and Cybersecurity
- Managed IT and Long-Term Support

Then show supporting services:

- Web Development
- Mobile Development
- UI/UX Design
- ERP Integration
- DevOps
- Consulting
- Maintenance
- Monitoring

## UX Success Rule

Every section must answer at least one of these visitor questions:

- Is this for my organization?
- What business problem does it solve?
- Can I trust this company?
- What should I click next?
