# Hero Slider Specification

## Purpose

The homepage hero slider introduces Shamash IT's five core solution areas while preserving one unified enterprise brand system.

The slider should show that Shamash IT is not a one-product company and not a simple web agency. It is an enterprise technology partner with specialized platforms and strategic services.

## Slides Required

The slider must include exactly these five primary slides:

1. XpertFactor
2. Factorix
3. Document Management
4. AI Automation and Digital Transformation
5. Enterprise Web and Mobile

## Visual Direction

Each slide must use:

- White or very light neutral background
- Subtle blue-to-indigo gradient accents
- Midnight Navy headings
- Shamash Blue primary buttons
- Enterprise Indigo secondary details
- Very limited Compass Gold accents
- Realistic software interface visuals or meaningful workflow diagrams

Do not use:

- Generic buildings
- Generic robots
- Cyberpunk scenes
- Floating AI cubes
- Unrelated futuristic backgrounds
- Dark full-page hero backgrounds
- Random stock photography

## Layout

### Left Content

Each slide includes:

- Category label
- Product or solution name
- Business-focused headline
- Short value proposition
- Primary CTA
- Secondary CTA
- Capability tags

### Right Visual

Each slide includes:

- Dashboard mockup, workflow visual, or product interface composition
- Optional small callout panels
- Optional metric highlights
- No meaningless decoration

## Behavior

Required slider behavior:

- Auto-rotate every 8 seconds
- Pause on hover
- Pause when the browser tab is inactive
- Pause when focused by keyboard if needed
- Previous and next controls
- Dot or segmented indicators
- Swipe support on touch devices
- Keyboard arrow support
- Respect `prefers-reduced-motion`
- Use transition duration around 500ms to 700ms

## Accessibility

- Use semantic region labeling.
- Announce slide changes politely, not aggressively.
- Ensure controls are buttons, not divs.
- Provide visible focus states.
- Do not trap keyboard focus.
- Do not auto-advance when `prefers-reduced-motion` is active unless the user explicitly starts playback.
- Keep all text readable at mobile sizes.
