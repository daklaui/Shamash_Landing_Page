# Shamash IT AI-Agent Website Build Pack

This folder contains the complete instruction pack for building the Shamash IT website with a coding agent such as Codex, Claude Code, or another autonomous development agent.

The pack converts the approved strategy and brand direction into durable implementation instructions. It should be treated as the source of truth before starting the Next.js build.

## Core Direction

Build a bright, premium, enterprise website for Shamash IT.

The website must position Shamash IT as a strategic technology partner for enterprise software, FinTech platforms, digital transformation, AI automation, cloud infrastructure, cybersecurity, and managed IT services.

The website must not look like a generic web agency, startup template, cyberpunk AI page, or dark technology landing page.

## Required Stack

- Next.js with App Router
- TypeScript
- Tailwind CSS
- Data-driven content modules
- Reusable components
- Accessible and responsive UI
- Performance-focused implementation

## File Map

- `AGENTS.md`: Operating instructions for AI coding agents.
- `brand-guidelines.md`: Brand identity, color system, positioning, and visual rules.
- `website-structure.md`: Sitemap, homepage flow, page responsibilities, and navigation model.
- `ui-ux-system.md`: Layout, typography, spacing, components, motion, and visual style.
- `content-guidelines.md`: Messaging, tone, content hierarchy, CTAs, and forbidden language.
- `hero-slider-spec.md`: Exact homepage hero slider requirements and slide content.
- `component-architecture.md`: Suggested data models, components, and file organization.
- `responsive-accessibility.md`: Responsive behavior and accessibility requirements.
- `seo-performance.md`: SEO, metadata, semantic structure, and performance requirements.
- `implementation-plan.md`: Step-by-step implementation plan.
- `acceptance-criteria.md`: Final checklist before delivery.
- `master-build-prompt.md`: Copy-ready prompt for a coding agent.

## How To Use

1. Give this entire folder to the coding agent.
2. Start with `AGENTS.md`.
3. Use `master-build-prompt.md` as the main task prompt.
4. Treat every other file as required project context.
5. Build the site with reusable data-driven components, not hardcoded repeated sections.
6. Verify the result against `acceptance-criteria.md`.

## Most Important Rules

- Use the unified Shamash IT brand system for all solutions.
- Preserve the 70/20/8/2 visual color ratio.
- Use `#35A8DE`, `#505CA2`, `#E9AE11`, `#242850`, white, and neutrals.
- Keep the design bright, clean, premium, and enterprise-focused.
- Include a five-slide hero slider:
  - XpertFactor
  - Factorix
  - Document Management
  - AI Automation and Digital Transformation
  - Enterprise Web and Mobile
- Make services prominent, not hidden below product cards.
- Use audience-based routing so visitors find the right solution quickly.
- Avoid generic buildings, robots, cyberpunk visuals, unrelated futuristic scenery, and stock-like decoration.
- Build with accessible, responsive, performant Next.js, TypeScript, and Tailwind.
