# Acceptance Criteria

Use this checklist before considering the Shamash IT website complete.

## Brand

- [ ] The design is bright, premium, and enterprise-focused.
- [ ] The site uses one unified Shamash IT visual system.
- [ ] Color usage follows the 70/20/8/2 ratio.
- [ ] Shamash Blue `#35A8DE` is the primary action color.
- [ ] Enterprise Indigo `#505CA2` is used for secondary enterprise accents.
- [ ] Compass Gold `#E9AE11` is used sparingly.
- [ ] Midnight Navy `#242850` is used for headings, footer, and selected premium panels.
- [ ] No unrelated dominant colors replace the brand palette.

## Forbidden Visuals

- [ ] No generic buildings or decorative skyscraper scenes.
- [ ] No generic robots.
- [ ] No cyberpunk visuals.
- [ ] No floating AI cubes.
- [ ] No dark full-page default background.
- [ ] No random stock photos of people.
- [ ] No decorative visuals that fail to explain a product, workflow, or business result.

## Homepage

- [ ] Homepage includes a five-slide hero slider.
- [ ] Slider includes XpertFactor.
- [ ] Slider includes Factorix.
- [ ] Slider includes Document Management.
- [ ] Slider includes AI Automation and Digital Transformation.
- [ ] Slider includes Enterprise Web and Mobile.
- [ ] Audience routing appears directly after or within the first homepage experience.
- [ ] Services are prominent and visually strong.
- [ ] Product highlight sections exist for all five solution areas.
- [ ] Final CTA is clear and conversion-focused.

## UX

- [ ] A bank visitor can quickly find XpertFactor.
- [ ] A company manager can quickly find Factorix.
- [ ] A document-management visitor can quickly find the document solution.
- [ ] An automation visitor can quickly find AI Automation.
- [ ] A custom software visitor can quickly find Web and Mobile.
- [ ] Every major section includes a clear next action.
- [ ] Navigation is clear on desktop and mobile.

## Technical Implementation

- [ ] Built with Next.js App Router.
- [ ] Built with TypeScript.
- [ ] Built with Tailwind CSS.
- [ ] Repeated content is data-driven.
- [ ] Components are reusable.
- [ ] No unnecessary duplicated markup for products and services.
- [ ] Semantic HTML is used.
- [ ] Page metadata is implemented.

## Accessibility

- [ ] Keyboard navigation works.
- [ ] Hero slider controls are accessible buttons.
- [ ] Focus states are visible.
- [ ] Text contrast is sufficient.
- [ ] Motion respects `prefers-reduced-motion`.
- [ ] Mobile menu is accessible.
- [ ] Forms have labels and validation states if forms are present.

## Responsive

- [ ] Layout works at 320px width.
- [ ] Layout works on mobile.
- [ ] Layout works on tablet.
- [ ] Layout works on desktop.
- [ ] Text does not overflow buttons, cards, or sections.
- [ ] Dashboard mockups do not break layout.

## Performance and SEO

- [ ] Lighthouse Performance target is 90+.
- [ ] Lighthouse Accessibility target is 95+.
- [ ] Lighthouse SEO target is 95+.
- [ ] Images are optimized.
- [ ] Layout shift is controlled.
- [ ] Sitemap is present.
- [ ] Robots file is present.
- [ ] Each page has unique metadata.

## Content

- [ ] Copy is business-oriented and clear.
- [ ] Shamash IT is not positioned as a generic web agency.
- [ ] Product copy explains audiences, problems, capabilities, and outcomes.
- [ ] Service copy shows depth across engineering, AI, cloud, cybersecurity, and support.
- [ ] CTAs are specific and useful.
