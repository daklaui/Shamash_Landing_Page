# SEO and Performance Requirements

## SEO Goal

The website should be discoverable for Shamash IT's main markets and capabilities:

- Enterprise software Tunisia
- FinTech software
- Factoring software
- ERP software for companies
- Document management system
- AI automation for businesses
- Digital transformation services
- Managed IT services
- Cloud infrastructure and cybersecurity
- Web and mobile application development

## Metadata

Every page must include:

- Unique title
- Unique description
- Canonical URL when domain is known
- Open Graph title
- Open Graph description
- Open Graph image placeholder or generated brand image
- Twitter card metadata if relevant

## Recommended Homepage Metadata

Title:

```txt
Shamash IT | Enterprise Software, FinTech Platforms and AI Automation
```

Description:

```txt
Shamash IT builds secure enterprise software, factoring platforms, ERP systems, document management solutions, AI automation, cloud infrastructure and managed IT services for organizations in Tunisia, Africa and Europe.
```

## Structured Data

Add JSON-LD where appropriate:

- `Organization`
- `WebSite`
- `Service`
- `SoftwareApplication` for product pages when useful
- `FAQPage` for FAQ sections

## Semantic Structure

Use one `h1` per page.

Use headings in logical order:

- `h1` for page topic
- `h2` for major sections
- `h3` for cards and feature groups

Do not use headings only for visual sizing.

## Performance

Targets:

- Lighthouse Performance: 90+
- Lighthouse Accessibility: 95+
- Lighthouse Best Practices: 95+
- Lighthouse SEO: 95+
- Initial JavaScript kept modest
- No heavy animation library unless necessary
- Images optimized with Next.js image handling where real images are used

## Core Web Vitals

Optimize for:

- LCP under 2.5s
- CLS under 0.1
- INP under 200ms

## Asset Rules

- Prefer HTML/CSS dashboard mockups for product visuals.
- Use SVG icons from a consistent library.
- Avoid large generic stock images.
- Compress any bitmap assets.
- Use meaningful dimensions to prevent layout shift.

## Technical SEO

Include:

- `robots.txt`
- `sitemap.xml`
- Open Graph defaults
- Clean readable URLs
- Descriptive link labels
- Breadcrumbs on deeper pages if implemented

## Content SEO

Avoid keyword stuffing.

Use natural business language:

- Secure digital factoring platform
- Complete business management platform
- Intelligent document workflows
- Practical AI automation
- Enterprise architecture for web and mobile applications

Every important solution page should clearly state:

- Who it is for
- What problem it solves
- What features it includes
- What business outcomes it creates
- How to request a demo or consultation
